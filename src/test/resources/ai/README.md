# Learned demo fixtures

`e1m1-learned.lmp` contains only player inputs, generated by this repository's
archive explorer with seed 1, skill 3, normal gameplay flags, and the standard
E1M1 start. It contains no WAD assets or pre-authored route.

Discovered on attempt 68; 14,568 tics (416.229 game seconds). Verified through
both route replay and the engine's external demo loader. WAD SHA-256:
`6fdf361847b46228cfebd9f3af09cd844282ac75f3edbb61ca4cb27103ce2e7f`.

The regression copies it to `winning.lmp` because the vanilla lump loader
requires demo filename bases of at most eight characters. The test skips
when this particular local WAD is unavailable; a skipped test does not verify
completion. This is a port-specific replay fixture, not a claim of compatibility
with the original C executable. The learner never loads this fixture to train.

## E1M2

`e1m2-learned.lmp` contains only player inputs produced by this repository's
seed-1 archive explorer, skill 3, standard E1M2 pistol start and normal flags.
It uses the same WAD hash above. The initial completion was found on attempt 8
at 19,894 tics; two further tics were removed by attempt 433. The fixture is
that 19,892-tic (568.343-second) verified recording. It contains no WAD assets,
human-authored route, or hardcoded switch/exit coordinates.

The E1M2 regression replays it, observes keys and successful switch interactions,
then automatically generates and verifies a route within twice E1M2's 75-second
par. The original milestone proposal completed in 2,388 tics (68.229 seconds).
The later equipment-aware sixth following variant also collects armor and a
chaingun, completing in 3,194 tics (91.257 seconds). The assertion remains the
150-second threshold rather than a fixed historical completion time. The matching-WAD test skips when that local WAD is unavailable.
