New `.lmp` recordings are ignored by Git and remain local. The E1M4–E1M9,
red-door and revised-stair replay tests skip if their recordings are absent.
Previously tracked E1M1–E1M3 fixtures remain versioned and required. To run the
optional replay tests elsewhere, copy the matching local recordings into this
directory using the filenames documented below; the matching WAD is also needed.

# Learned demo fixtures

`e1m1-learned.lmp` contains only player inputs, generated by this repository's
archive explorer with seed 1, skill 3, normal gameplay flags, and the standard
E1M1 start. It contains no WAD assets or pre-authored route.

Discovered on attempt 68; 14,568 tics (416.229 game seconds). Verified through
both route replay and the engine's external demo loader. WAD SHA-256:
`6fdf361847b46228cfebd9f3af09cd844282ac75f3edbb61ca4cb27103ce2e7f`.

The regression copies it to `winning.lmp` because the vanilla lump loader
requires demo filename bases of at most eight characters. The test skips
when this particular local WAD is unavailable; a skipped test does not verify
completion. This is a port-specific replay fixture, not a claim of compatibility
with the original C executable. Fresh training never loads these fixtures automatically.

## E1M2

`e1m2-learned.lmp` is the current-engine **1,893-tic / 54.09-second** result
from `training/episode1-nav/e1m2-seed2-import/`, attempt 19. It finishes with
14 health and the red key. That experiment imported the learner's historical
E1M2 milestone as surviving input prefixes, then found a new completion on
attempt 7 and optimized it. It is not an unseeded experiment. The test verifies
keys, observed switch activation, normal gameplay flags, fingerprinted replay
and external demo playback within twice par.

The previous 19,892-tic fixture no longer completes after restoring the missing
special-sector damage in the engine. Its historical performance is documented
in LEARNING.md; it is not used as a current completion regression.

## E1M4

`e1m4-learned.lmp` contains the existing learner's seed-6 result: **2,134 tics /
60.971 seconds**, skill 3, normal monsters, standard pistol start, same WAD hash
as above. No algorithm changes or human route were needed. Fresh exploration
found its first completion on attempt 187 (6,343 tics / 181.23 seconds), then
automatic optimization produced this recording on attempt 219. It finishes
through the normal exit to E1M5 with both blue/yellow keys, 84 health, 99 armor,
a shotgun, eight shells and 12 kills.

The matching-WAD regression checks completion below E1M4's 90-second par, both
keys, fingerprinted route replay, external-demo playback and the normal E1M5
transition. This fixture contains only player inputs; fresh training does not
load it. The separately saved seed-2 125.89-second milestone was an independent
search and was not the source of this optimized recording.

## E1M8

`e1m8-learned.lmp` is a **2,043-tic / 58.37-second** skill-3 pistol-start
completion with normal monsters, below twice the 30-second par. It acquires a
chaingun and ammunition, defeats both Barons, opens the exit and reaches the
normal episode finale. The regression checks both Barons dead, a living player
at ten health or less, completion within 2×par, fingerprinted replay, external
demo playback and the `ga_victory` transition.

It was generated by shortening a self-generated equipment prefix to 612 tics,
then replay-based combat beam search (width 32, horizon 14) and navigation through
learned switch/teleport landmarks (turn limit 8192). The final source is
`training/twopar-shortprep-combat/h14-w32-g0/exit8192/trial.lmp`.
These offline experiments are saved in the demo bundle; the normal trainer does
not automatically invoke the combat beam harness or load these fixtures.

## E1M9 staircase / locked-door regression fixtures

`e1m9-stairs-fixed.lmp` is the revised **9,693-tic / 276.94-second** skill-3
pistol-start completion. The fastest `e1m9-learned.lmp` remains unchanged for
comparison. The revised route reaches all three keys, finishes with 59 health,
and has one red-door denial instead of 31. It was discovered by the corrected
archive explorer from a self-generated 273-tic yellow-key prefix (seed 2,
attempt 111), then shortened by 1,000 ordinary optimizer proposals (best at 695).
No manually authored route or game-state grants were used.

`e1m9-red-door.lmp` contains the first **544 tics** of the old fastest recording,
ending on its first red-key rejection. It is deliberately unfinished. Its test
checks that replay reconstructs the observed lock, unrelated progress and a
blue key do not clear it, the red key does, and subsequent controller movement
does not generate another red-door rejection. The engine's recorded inputs are
replayed normally; key grants occur only inside this focused test assertion.

Both use the same WAD hash as the other fixtures. Detailed generation logs,
movement comparison and replay verification are in `training/e1m9-stair-fix/`.
